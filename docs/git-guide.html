🔁 매번 하는 5단계

작업할 때마다 이 순서 그대로.

  1. 최신본부터 받기  git pull origin develop
    남들이 한 최신 작업부터 내려받아요.
  2. 내 복사본(브랜치) 만들기  git checkout -b feature/내작업
    여기서만 작업해요. 원본은 절대 직접 X
  3. 작업하고 중간 저장  git commit -m "feat: ○○ 추가"
    의미 단위로. “최종”, “수정” 같은 메시지 금지.
  4. 내 복사본 올리기  git push origin feature/내작업
  5. “합쳐주세요” 요청 (PR)
    무엇을 했는지 + 어떻게 확인하는지 적어요.

🥁 합칠 때 — “머지 4박자”

동시에 두 명이 합치면 충돌나요. 한 명씩 순서대로!

1
합치기 전, 최신본을 내 복사본에 먼저 반영
바뀐 게 뭔지 확인하고 정리 (git pull origin develop)
2
잘 돌아가는지 확인 후 PR
앱 실행해서 기능 되는지 보기
3
내 차례에만 합치기
작업보드에 “머지중 🔴” 켜고, 앞사람 끝난 뒤 진행
4
합친 뒤엔 다들 다시 받기
방금 합쳐진 최신본을 각자 git pull

🚫 이건 절대 하지 마세요

사고의 대부분이 여기서 나요.

✕
원본(main/develop)에 직접 올리기검토 없이 원본 훼손 = 다 같이 망함
✕
받기(pull) 안 하고 시작옛날 버전 위에 작업 → 남 작업 덮어씀
✕
공통 파일 말없이 수정“저 이거 손댈게요” 한마디면 예방
✕
비밀번호·키(.env) 올리기금고 비번을 게시판에 붙이는 격
✕
큰 데이터(3.7GB) 올리기서버가 터져요
✕
“최종”, “진짜최종” 저장나중에 뭘 바꿨는지 못 찾음

🆘 막히면?

혼자 끙끙대지 마세요.

  • 충돌(<<<<< 표시)이 났다 → 같은 파일 건드린 사람에게 바로 물어보기. 대충 덮어쓰기 X
  • 처음이라 무섭다 → 팀이 더미(연습용) 브랜치로 한 번 같이 리허설해보기
  • 뭘 하는 중인지 모르겠다 → 작업보드(누가·뭘·상태) 확인

⭐ 딱 3가지만 기억하세요

  1. 작업 전 “받기(pull)” — 남들 최신부터
  2. 내 복사본에서만 작업 — 원본 직접 X
  3. 공통 파일 손대기 전 “한마디” + 합칠 땐 순서대로
