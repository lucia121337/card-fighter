# 카드파이터 홈 추천 흐름 재구성 설계

## 1. 결정과 목표

기존 홈은 서비스 목적과 브랜드 색상은 명확하지만, 세 개의 진입 경로와 세 번의 3열 카드 구성이 반복되어 추천 서비스보다 기능 포털처럼 보인다. 이번 변경은 기존 파란색·남색 브랜드와 카드 데이터 연결을 유지하면서 사용자가 더 빨리 추천을 시작하도록 정보 구조와 화면 리듬을 재설계한다.

검토한 방향은 다음 세 가지다.

1. 순서와 문구만 바꾸는 소폭 수정: 안전하지만 반복되는 카드 구조를 해결하지 못한다.
2. 브랜드와 전체 UI를 전면 개편: 차별화 효과는 크지만 기존 페이지와의 일관성 및 작업 범위를 벗어난다.
3. 추천 흐름 중심 재구성: 기존 디자인 언어를 유지하되 진입 선택을 두 개로 줄이고 카드·목록·상태 영역의 역할을 구분한다.

승인된 방향은 3번이다.

## 2. 제품 원칙

1. 처음 방문한 사용자의 첫 선택은 `소비 입력 추천`과 `혜택별 탐색` 두 가지로 제한한다.
2. 비교는 시작 경로가 아니라 카드를 담은 뒤 이어가는 상태 기반 기능으로 다룬다.
3. 추천 카드에는 선정 상황, 주요 혜택, 전월실적, 연회비와 다음 행동을 함께 제공한다.
4. 같은 형태의 3열 카드를 연속해서 사용하지 않는다.
5. 데이터 출처와 추천 한계를 첫 행동 가까이에서 알린다.
6. 캐시백은 상품 카드가 아닌 금액 순위 목록으로 보여 추천 카드와 시각적 역할을 구분한다.

## 3. 새 정보 구조

홈의 세로 순서는 다음과 같다.

1. 추천 시작 히어로
2. 생활 혜택 빠른 선택
3. 상황별 대표 카드
4. 캐시백 혜택 순위
5. 비교함 이어하기
6. 카드 연구소
7. 데이터 신뢰 정보

기존의 `어떤 방식으로 찾아볼까요?` 3열 경로 영역은 제거한다. 히어로의 두 CTA와 빠른 혜택 선택이 같은 역할을 더 짧게 수행하기 때문이다.

## 4. 영역별 설계

### 4.1 추천 시작 히어로

- 핵심 문구 `나에게 어떤 카드가 유리한지 찾아보세요`는 유지한다.
- 기본 행동은 `1분 맞춤 추천 시작`, 보조 행동은 `혜택으로 빠르게 찾기` 두 개만 둔다.
- 오른쪽 결과 패널은 설명 목록이 아니라 실제 추천 결과 예시처럼 보이게 구성한다.
- 예시에는 `예상 월 혜택`, `연회비 제외 실질 이득`, `전월실적`, `추천 이유`를 표시한다.
- 데이터 출처와 참고용 결과라는 신뢰 문구를 CTA 아래에 짧게 배치한다.
- 데스크톱 첫 화면에서 히어로와 빠른 혜택 선택의 시작이 함께 보이도록 높이를 줄인다.

### 4.2 생활 혜택 빠른 선택

- 생활비, 쇼핑, 교통, 주유, 카페·디저트, 여행·숙박, 항공마일리지, 프리미엄 여덟 개를 유지한다.
- 장식용 영어 소제목 `QUICK PICK`은 제거하고 `혜택으로 바로 찾기`라는 기능 중심 제목을 사용한다.
- 선택 시 기존 전체카드 섹션과 카테고리 필터를 그대로 사용한다.
- 모바일에서는 2열 버튼으로 보여 스크롤 길이와 탐색 시간을 줄인다.

### 4.3 상황별 대표 카드

- 제목을 `지금 주목할 카드`에서 `생활 상황별 대표 카드`로 바꿔 선정 기준을 명확하게 한다.
- 첫 카드는 대표 카드로 크게 보여주고, 나머지 두 카드는 더 압축된 후보 카드로 배치한다.
- 모든 카드에는 카드 이미지, 카드사·카드명, 추천 상황, 핵심 혜택, 전월실적, 연회비, 상세 보기와 비교함 담기를 제공한다.
- 원문 혜택 요약을 그대로 길게 노출하지 않고 첫 번째 또는 핵심 혜택만 읽기 좋은 문장으로 표시한다.
- 대표 카드 선정 로직과 기존 상세·비교 연결은 유지한다.

### 4.4 캐시백 혜택 순위

- 3열 캐시백 카드 대신 1위부터 3위까지 세로 순위 목록을 사용한다.
- 각 행에는 순위, 카드사, 플랫폼, 최대 금액, `혜택 확인` 행동을 표시한다.
- 가장 높은 금액만 색으로 강조하고 나머지는 차분한 표 형태로 구성한다.
- 전체 캐시백 화면으로 가는 링크를 제목 우측에 둔다.

### 4.5 비교함 이어하기

- 비교함이 비어 있으면 작은 안내 영역과 `비교할 카드 찾기` 행동을 보여준다.
- 1장이 담겼으면 `한 장 더 담으면 비교할 수 있어요`를 표시한다.
- 2장 이상이면 담긴 장수와 `바로 비교하기`를 강조한다.
- 신규 사용자의 추천 시작과 경쟁하지 않도록 추천 카드와 캐시백 아래에 배치한다.

### 4.6 카드 연구소와 신뢰 정보

- 카드 연구소는 맨 아래의 보조 탐색 영역으로 유지한다.
- 영어 장식 라벨 대신 `취향으로 찾기`처럼 사용자가 이해하는 표현을 쓴다.
- 데이터 출처, 갱신 기준, 신청 전 상품설명서 확인 문구를 푸터에 유지한다.
- 히어로에는 이 내용을 한 줄로 축약해 중복이 아니라 신뢰의 선요약과 상세 안내 관계를 만든다.

## 5. 시각 방향

- 기존 브랜드 블루 `#145CE6`, 네이비 `#10244A`, 흰색과 차가운 회색 배경을 유지한다.
- 분홍색 복싱 글러브 포인트는 히어로의 얇은 강조선과 핵심 숫자에만 제한해 브랜드 서명으로 사용한다.
- 둥근 모서리와 그림자는 계층적으로 줄인다. 핵심 결과 패널과 대표 카드에만 깊이를 주고, 순위 목록과 보조 영역은 선과 여백으로 구분한다.
- 장식용 이모지는 빠른 혜택 버튼에서 작은 단서로만 사용하고, 별도의 색 원형 아이콘은 제거한다.
- 영문 장식 소제목을 줄이고 한국어 기능명으로 교체한다.
- 폰트는 기존 GmarketSans와 Noto Sans KR 두 개를 유지해 다른 페이지와의 일관성을 지킨다.

## 6. 반응형과 접근성

- 데스크톱은 최대 1180px 안에서 히어로 2열, 대표 카드 `큰 카드 1 + 작은 카드 2` 구성을 사용한다.
- 태블릿에서는 대표 카드 세 장을 2열 뒤 1열로 자연스럽게 줄인다.
- 모바일 390px에서는 히어로를 한 열로 만들고 결과 예시 높이를 압축한다.
- 모바일 혜택 버튼은 2열, 카드와 캐시백 순위는 1열로 배치한다.
- 모든 링크와 버튼의 최소 높이를 44px로 맞춘다.
- 키보드 포커스, 이미지 대체 텍스트, 충분한 텍스트 대비를 유지한다.
- 모바일 상단 메뉴는 현재의 가로 스크롤 방식을 유지하되 첫 두 핵심 메뉴가 보이도록 한다.

## 7. 데이터와 기능 연결

- 카드 데이터는 기존 `DATA`와 `selectFeaturedCards`를 사용한다.
- 캐시백 데이터는 기존 `getPlatformCompanies('전체보기')`와 `selectCashbackHighlights`를 사용한다.
- 카테고리 선택은 기존 `activeCategories`, `.cat-pill`, `applyFilters()`를 사용한다.
- 비교 상태는 기존 `compareList`, `toggleCompare`, `goCompare`를 사용한다.
- 새로운 API, 저장 형식, 추천 알고리즘은 만들지 않는다.
- 데이터가 없으면 각 영역에 설명과 이동 가능한 복구 행동을 표시한다.

## 8. 변경 파일과 범위

- `index.html`: 홈 영역의 순서와 의미 구조 변경
- `home-recommendation.css`: 대표 카드, 순위 목록, 비교 상태, 반응형 스타일 재구성
- `home-recommendation.js`: 새 HTML 구조에 맞춘 카드·캐시백 렌더링과 비교 상태 표시
- `src/picking/test_home_recommendation.js`: 렌더링 계약과 상태별 문구 회귀 테스트

기존 전체카드, 상세, 캐시백 본문, 계산기, 할인가맹점, 카드 연구소 페이지는 재설계하지 않는다.

## 9. 성공 기준

- 첫 화면에서 서비스 목적과 두 개의 추천 시작 방법을 이해할 수 있다.
- 기존 3열 경로 카드 영역이 제거되고 빠른 혜택 선택이 히어로 바로 뒤에 나온다.
- 대표 카드 영역과 캐시백 영역이 서로 다른 시각 구조를 갖는다.
- 추천 카드 3개와 캐시백 상위 3개가 실제 데이터에서 표시된다.
- 비교함 0장, 1장, 2장 이상의 상태가 다른 문구와 행동으로 표현된다.
- 데스크톱과 390px 모바일에서 가로 스크롤이 없고 주요 버튼 높이가 44px 이상이다.
- 기존 카드 필터, 상세 보기, 비교함, 캐시백 이동과 계산기가 정상 작동한다.
