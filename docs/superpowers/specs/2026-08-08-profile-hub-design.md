# 소비 프로필 허브 — 홈·계산기·월드컵 연결 (A안)

- 작성일: 2026-08-08 · 목표: **발표 시연 "한 줄기 스토리"** — 소비 한 번 입력 → 담당 3영역(홈·혜택계산기·카드월드컵)이 전부 내 기준으로.
- 승인: 사용자 A안 확정("네가 추천한거 작업해줘").

## 구성

**profile.js (신규 공용 모듈)** — benefit-calc.js 패턴. localStorage `cf_profile_v1`.
`CardProfile.load()/save(spendWon, prevWon)/clear()`. spend는 {카테고리: 원}, 양수만 저장. 빈 저장은 무시(null).

**홈 (index.html + 신규 home-profile.js)** — index엔 script 3줄만 추가(profile.js·benefit-calc.js·home-profile.js), 마크업 무변경(주입식).
- 프로필 없음: 대표카드 섹션 위에 **퀵 입력 스트립**(푸드·마트/편의점·온라인쇼핑·주유·통신 5칸, 만원) → 저장.
- 프로필 있음: benefits_structured.json + cards.json(활성 1,111장) 지연 로드 → BenefitCalc로 **월 순이득 Top3** 계산,
  대표카드 그리드를 "내 소비 기준 Top3 · 월 ○원 이득"으로 교체(기존 .home-feature-card 마크업 재사용, 비교담기 위임 그대로 동작).
  스트립은 요약("월 ○만원 기준 · 수정/초기화")으로 전환.

**혜택계산기 (calculator.html)**
- 로드 시 프로필 **자동 채움**(만원 환산) + "🔗 프로필 연동" 안내. 입력 변경 시 recalc()에서 프로필 저장(빈 입력은 저장 안 함).
- 순위 카드에 **[근거 보기]** 토글: 해당 카드 calc 재실행 → 카테고리별 (율×지출→적용액), 정액/주유, 한도 clamp, 연회비 차감 내역 패널.

**카드월드컵 (tournament.html)**
- STEP2: 프로필 지출>0 카테고리 **자동 선택**(SELECTED 비었을 때만).
- STEP3: 금액·전월실적 **자동 채움** + 안내 라인, updatePool 즉시 실행.
- 결과: **"취향 우승 vs 데이터 1위" 클로저** — POOL[0](시드1)과 우승 비교. 일치→"🎯 취향=이득!",
  불일치→money트랙은 월 ○원 차이, unit트랙은 단위 표기 비교 + 데이터1위 상세 링크. (발표 하이라이트)

## 원칙
- 단위: 프로필은 항상 **원** 저장, 화면은 만원 표시. 마일/포인트 원 환산 금지 유지.
- 실패 안전: localStorage 예외 무시, 프로필 없으면 모든 화면 기존 동작 100% 동일(무회귀).
- 파일 경계: index.html 변경은 script 태그만(공통파일 최소 접촉). 나머지는 담당 파일 + 신규 2파일.

## 검증
프로필 없음 무회귀 → 홈 입력→Top3 → 계산기 프리필/근거 → 월드컵 프리필→결과 클로저, 전부 브라우저 확인.
