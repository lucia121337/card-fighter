# 홈 카드 수·오늘의 매치 투명성 개선 설계

## 목적

홈의 카드 수와 오늘의 매치 추천 근거를 실제 데이터와 일치시킨다. 사용자는 추천 카드가 왜 선택됐는지, 어떤 소비 금액을 기준으로 계산했는지 확인하고 카드 전체를 눌러 상세 페이지로 이동할 수 있어야 한다.

## 데이터 기준

- 홈 카드 수와 오늘의 매치 후보는 `cards_list.json`을 단일 기준으로 사용한다.
- 홈의 카드 수는 JSON 배열 길이로 계산해 자동 표시하며 숫자를 HTML에 고정하지 않는다.
- `benefits_structured.json`에 혜택 데이터가 있고 계산 결과의 금전 혜택이 0원보다 큰 카드만 매치 순위에 포함한다.
- 순위는 `월 예상 혜택 - 연회비 월 환산액`인 월 순이득 내림차순이다. 순이득이 같으면 월 환산 연회비가 낮은 카드가 앞선다.
- 오늘 날짜에 따른 무작위 교체는 하지 않는다. `오늘의 매치`는 현재 적용 중인 소비 기준으로 계산한 1위와 2위의 비교를 뜻한다.

## 소비 기준

저장된 소비 프로필이 없으면 다음 표준 소비를 사용한다.

| 항목 | 월 금액 |
|---|---:|
| 푸드 | 400,000원 |
| 카페·디저트 | 100,000원 |
| 마트·편의점 | 250,000원 |
| 온라인쇼핑 | 200,000원 |
| 교통 | 70,000원 |
| 주유 | 100,000원 |
| 통신 | 70,000원 |
| 합계 | 1,190,000원 |

저장된 소비 프로필이 있으면 프로필의 소비 항목과 전월실적을 사용한다. 전월실적이 따로 없으면 소비 항목 합계를 전월실적으로 사용한다.

## 오늘의 매치 UI

- 상단 라벨에 `표준 소비 기준 · 월 119만 원` 또는 `내 소비 기준 · 월 합계`를 표시한다.
- `기준 보기` 버튼을 누르면 현재 적용 중인 소비 항목별 금액을 작은 그리드로 펼친다. 다시 누르면 닫힌다.
- 두 카드 모두 카드 전체가 상세 링크다. 링크는 `detail.html?idx=<카드번호>` 형식을 사용한다.
- 각 카드에는 카드사, 카드명, 월 순이득, 추천 이유를 표시한다.
- 1위 카드에는 현재의 우승 벨트 표현을 유지한다.
- 키보드 초점, `aria-expanded`, 기준 영역 연결, 충분한 클릭 영역을 제공한다.

## 추천 이유 생성

추천 이유는 계산 결과의 실제 혜택 기여 행 중 적용 혜택 금액이 큰 순서로 최대 2개를 사용한다.

- 기본 문구: `마트·편의점 5%로 약 25,000원 혜택`
- 두 번째 줄: `예상 혜택 70,000원 - 월 연회비 1,250원`
- 강조 값: `월 순이득 68,750원`

적용 혜택 행을 만들 수 없으면 카드의 `top_benefit_summary`를 추천 이유로 사용한다. 혜택 데이터가 없거나 계산 결과가 0원 이하인 카드는 순위에서 제외한다.

## 구현 경계

- `index.html`: 카드 수가 들어갈 식별 요소와 `home-match.js` 로드만 추가한다.
- `home-match.js`: 표준 소비, 순위 계산, 추천 이유 생성, 카드 수 문구와 매치 HTML 생성을 담당하는 브라우저·Node 공용 순수 모듈이다.
- `home-profile.js`: `cards_list.json`·혜택 데이터 로드, 저장 프로필 선택, DOM 반영과 기준 펼치기 동작을 담당한다.
- `home-recommendation.css`: 매치 카드 링크, 추천 이유, 기준 펼침 영역의 반응형·접근성 스타일을 담당한다.
- `src/picking/test_home_match.js`: `home-match.js`의 카드 수, 표준 소비, 순위, 추천 이유, 상세 링크를 Node 테스트로 검증한다.

## 실패 처리

- `cards_list.json` 또는 혜택 데이터 로드 실패 시 기존 안내 링크를 포함한 오류 문구를 보여준다.
- 계산 가능한 카드가 2장보다 적으면 매치를 억지로 만들지 않고 계산기에서 직접 확인하도록 안내한다.
- 카드 수를 읽지 못하면 숫자 없는 문구인 `수많은 카드가 싸웁니다`를 사용한다.

## 검증

- `cards_list.json`의 실제 길이가 홈 카드 수에 반영되는지 검사한다.
- 표준 소비 합계가 1,190,000원인지 검사한다.
- 순이득 내림차순과 동점 시 낮은 연회비 우선 규칙을 검사한다.
- 추천 이유가 실제 적용 혜택 금액이 큰 순서로 만들어지는지 검사한다.
- 두 카드가 올바른 상세 주소를 갖는지 검사한다.
- 저장 프로필 유무에 따라 기준 라벨과 상세 금액이 바뀌는지 검사한다.
- 주요 홈·상세·비교·계산기 페이지를 로컬 서버에서 확인한다.
